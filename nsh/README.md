# maplibre-nsh

MapLibre maps in [Native Shell](https://nsh.dev) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine into a native view of its own. It runs on macOS and iOS.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/nsh/) has how to use it
and run its example, [`examples/hello-map`](examples/hello-map).
