# maplibre-whisker

MapLibre maps in [Whisker](https://whisker.rs) apps, drawn by mln-rs through
[maplibre-rust-ui](https://github.com/birkskyum/maplibre-rust-ui)'s engine into a Swift or Kotlin
view of its own. It runs on iOS and Android.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/whisker/) has how to use
it and run its example,
[`examples/hello-map`](https://github.com/birkskyum/maplibre-rust-ui/tree/main/whisker/examples/hello-map).
