# maplibre-bevy

MapLibre maps in [Bevy](https://bevyengine.org) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine on a UI node drawn with Bevy's wgpu device. It runs on
macOS so far.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/bevy/) has how to use it
and run its example, [`examples/hello-map`](examples/hello-map).
