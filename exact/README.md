# maplibre-exact

MapLibre maps in [Exact](https://github.com/expo/exact) apps, drawn by mln-rs through
[maplibre-rust-ui](https://github.com/birkskyum/maplibre-rust-ui)'s engine on Exact's GPU canvas. It
runs on macOS, iOS and Android.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/exact/) has how to use it
and run its example,
[`examples/hello-map`](https://github.com/birkskyum/maplibre-rust-ui/tree/main/exact/examples/hello-map).
