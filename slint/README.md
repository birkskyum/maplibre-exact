# maplibre-slint

MapLibre maps in [Slint](https://slint.dev) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine on Slint's wgpu renderer. It runs on macOS so far.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/slint/) has how to use it
and run its example, [`examples/hello-map`](examples/hello-map).
