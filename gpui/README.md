# maplibre-gpui

MapLibre maps in [GPUI](https://www.gpui.rs) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine from IOSurfaces that GPUI's Metal renderer samples, with
nothing copied. It runs on macOS so far, with a change to GPUI in [`patches/zed`](patches/zed).

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/gpui/) has how to use it
and run its example, [`examples/hello-map`](examples/hello-map).
