# maplibre-rust-ui

MapLibre maps for Rust UI frameworks, drawn by [mln-rs](https://github.com/louwers/mln-rs), the Rust
port of MapLibre Native. This crate is the core the hosts build on, the map an app declares and the
engine that draws it.

An app uses it through the crate of its framework's host, `maplibre-slint`, `maplibre-egui`,
`maplibre-bevy`, `maplibre-nsh` or `maplibre-whisker`. [The
docs](https://birkskyum.github.io/maplibre-rust-ui/) have how to use each, [the map
model](https://birkskyum.github.io/maplibre-rust-ui/model/) and [the
API](https://birkskyum.github.io/maplibre-rust-ui/api/maplibre_rust_ui/).
