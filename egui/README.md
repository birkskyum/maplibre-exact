# maplibre-egui

MapLibre maps in [egui](https://www.egui.rs) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine on egui's wgpu renderer. It runs on macOS so far.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/egui/) has how to use it
and run its example, [`examples/hello-map`](examples/hello-map).
