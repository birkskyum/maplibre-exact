# maplibre-whisker

MapLibre maps in [Whisker](https://whisker.rs) apps, drawn by mln-rs through
[maplibre-rust-ui](../README.md)'s engine into a Swift or Kotlin view of its own. It runs on iOS and
Android.

[Its page in the docs](https://birkskyum.github.io/maplibre-rust-ui/hosts/whisker/) has how to use
it and run its example, [`examples/hello-map`](examples/hello-map).
